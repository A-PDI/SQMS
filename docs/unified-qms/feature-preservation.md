Reference: `A-PDI/QMS-Development` commit `9e534177cc4ebf08e559179bbb2af0b825313ec7`. The architecture assessment supplies context; its suggestions to redesign or simplify an existing workflow do not override the user's correction.

Added SQMS modules use the original shell and mapped original control styles.

Five boundary files are explicitly identified in the manifest: API requests, session state, local-auth configuration, added navigation entries, and the Next.js bootstrap. The build-time loader resolves the original Vite alias and public environment expression without editing screen files.
